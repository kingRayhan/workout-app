# Glossary (product vocabulary)

User-facing terms for Workoutland. Prefer these in UI copy and docs.

| Prefer | Avoid | Meaning |
| --- | --- | --- |
| **Workout** | Exercise set, routine pack | Named list of catalog exercises (e.g. “Legs + shoulders”) |
| **Schedule** | Weekday plan, assignment map | Which workout runs on Mon–Sun |
| **Daily todolist** | Checklist, daily log (in UI) | Today’s checkable exercise list — primary logging experience |
| **Activity** | Contribution graph (in UI) | Green-square heatmap of training days |
| **Catalog exercise** | — | Built-in trainer exercise (static) |
| **Machine** | Equipment card | Gym machine reference entry |
| **Log** (data only) | — | Stored completion record behind a todolist check |

**Core loop (copy):**  
Create a **workout** → put it on the **schedule** → open **Today** as a **daily todolist** → **Activity** turns green.
